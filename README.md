# VNKE - 一分钟商业智慧

> 用娱乐化的方式，让知识变得有趣

## 🚀 项目说明

这是一个静态网站项目，旨在打造"知识娱乐化"平台，通过轻松有趣的方式传递商业洞察、职场智慧和创业故事。

## 📁 项目结构

```
vnke-site/
├── index.html          # 主页面（包含所有 CSS 和 JS）
├── README.md           # 项目说明
└── .git/               # Git 仓库
```

## 🎯 核心功能

- **每日金句**：每天更新一条商业金句
- **商业冷知识**：有趣的商业历史和管理学知识
- **职场智慧**：实用的职场建议和思维模型
- **随机知识卡片**：点击获取随机惊喜内容
- **响应式设计**：完美适配手机、平板和桌面

## 🛠️ 部署步骤

### 方法 1：GitHub Pages（推荐）

1. 确保已登录 GitHub
2. 创建仓库 `hbtony123/vnke.github.io`
3. 执行以下命令：
   ```bash
   cd vnke-site
   git init
   git add .
   git commit -m "初始化 VNKE 网站"
   git branch -M main
   git remote add origin https://github.com/hbtony123/vnke.github.io.git
   git push -u origin main
   ```
4. 在 GitHub 仓库设置中启用 GitHub Pages
5. 访问 `https://vnke.com`（需配置 CNAME）

### 方法 2：手动部署

1. 将 `index.html` 上传到任何静态托管服务
2. 或使用 Netlify/Vercel 拖拽部署
